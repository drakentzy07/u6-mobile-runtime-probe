# HIGHFLY MU-0 Android Playable

Primer vertical slice jugable inspirado en la progresión MMORPG clásica, sin assets ni IP propietaria de MU.

## Qué incluye
- Android landscape + controles táctiles
- zona segura + campo de caza
- Goblin / Lobo / Esqueleto con IA simple
- combo básico, Giro AoE, Dash y Pociones
- HP/MP, EXP, nivel y oro
- drops de oro, pociones y equipo
- inventario/equipamiento con ATK/DEF/velocidad
- guardado local en el navegador

## Probar
Abrir `mu0/index.html` en un navegador moderno. En Android usar landscape.

Desktop QA: WASD/flechas, Space=ataque, Q=skill, E=poción, I=inventario.
