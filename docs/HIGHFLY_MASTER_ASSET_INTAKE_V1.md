# HIGHFLY — MASTER ASSET INTAKE v1

Estado: CANÓNICO · INTERIOR 2 / WORLD / SKILL 4
Tema permitido: medieval · vikingo · fantasy RPG.
Regla madre: REUSE FIRST. No entrar assets modernos, industriales contemporáneos o decorativos sin función temática.

## Gate de ingreso
Un asset entra al catálogo jugable/editor sólo si cumple:
1. Coherencia medieval/viking/fantasy.
2. Uso claro en Forja, Posada, Gremio, Ciudad, Combate, Loot o Crafting.
3. Formato WebGL utilizable (GLTF/GLB o conversión aprobada).
4. Licencia/procedencia apta para el destino donde se publique.
5. No es un duplicado peor de un asset ya curado.

## Blacklist temática
Battery, Computer, modern desk/office furniture, fuel barrel moderno, dynamite moderno, sci-fi, neon, monitors/screens, industrial contemporary props, plástico/contemporary kitchen fixtures y cualquier asset sin función medieval clara.

## Forja — contrato de layout
- Ninguna vitrina puede quedar flotando.
- Cada vitrina debe apoyar visualmente en el piso mediante zócalo/pedestal continuo.
- Los soportes verticales y racks de pared NO pueden quedar vacíos.
- Cada familia debe mostrar variedad sin repetir innecesariamente el mismo modelo.
- Entrada principal: hueco limpio; no colocar pared detrás de la puerta.
- Mostrador: madera/piedra medieval; nunca escritorio de oficina.
- Densidad objetivo showroom: ~44–48 armas/escudos visibles, manteniendo lectura y circulación.
- Armas largas usan menos densidad para evitar solapamiento.
