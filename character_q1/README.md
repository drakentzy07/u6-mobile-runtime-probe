# HIGHFLY Character Q1

Isolated lab successor to Character Q0. The foundation remains pinned to
`b40a9b68d1bac946976878d788cf21771cc8c0d3` and ClaudeCraft to
`9b57e49c9676d75962700f828cc00a50a9a988b5`.

Q-Male/Q-Female use the supplied Quaternius geometry, UVs, materials and authored
anatomical skin weights. Canonical animation vocabulary, rotations and timings
are preserved; bind positions and translation baselines adapt to human anatomy.
External class animation donors receive the same renderer-only retarget. Weapons
retain native attachment/grip handling with family-specific proportional fitting.

The lab presents ten circular native action-bar skills. Their native cast,
ground-aim, resource, cooldown and hold behavior remains authoritative. The old
comparison buttons have been removed from the playable surface.

Weapon inlays are stored per equipped mainhand item. The twelve audited receptors
for Warrior, Rogue and Mage keep their native BASE identity, primary damage,
school, resource cost, cooldown and presentation. A compatible accepted cast adds
one native burn, slow or short stun. Other classes retain native skills and their
audit status. This lab grants access to inlays for evaluation; it is not a finished
production mastery or multi-element progression system.

The workflow reconstructs both pinned repositories, checks anatomy and animation
samples, runs simulation/HUD/regression tests and TypeScript, builds the WebGL
bundle, then tests nine classes and all three visual bodies in a browser. Native
button casts and mobile layouts are checked before Pages deployment. Screenshots
and structured diagnostics are uploaded even if a gate fails.

Training App and Mobile Legends repositories are outside this change.
The pre-character affinity GOLD branch is preserved.
